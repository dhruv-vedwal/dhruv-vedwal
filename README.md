## 🚀 Currently Building

<div align="center">

# ProductLens

### AI-powered product demo generation

</div>

> **Give ProductLens a web app, a prompt and credentials — and it works through the application to create a polished product demonstration.**

```text
             ┌─────────────────────┐
             │      WEB APP        │
             └──────────┬──────────┘
                        │
                        ▼
             ┌─────────────────────┐
             │     AI AGENT        │
             │                     │
             │  Understand         │
             │  Explore            │
             │  Plan               │
             │  Interact           │
             │  Verify             │
             └──────────┬──────────┘
                        │
                        ▼
             ┌─────────────────────┐
             │   WORKFLOW TRACE    │
             └──────────┬──────────┘
                        │
                        ▼
             ┌─────────────────────┐
             │   DEMO GENERATION   │
             └──────────┬──────────┘
                        │
                        ▼
                  🎬 PRODUCT DEMO
```

**The bigger idea:** make software that can understand and operate web applications without requiring every interaction to be manually hardcoded.

**Stack**

`Next.js` `TypeScript` `Python` `FastAPI` `Playwright` `LLMs` `AI Agents` `Remotion`
